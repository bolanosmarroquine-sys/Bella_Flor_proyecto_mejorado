JavaScript (JS Vanilla)

El lenguaje que permite agregar comportamiento e interactividad a una página web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. Puede responder a acciones del usuario, modificar contenido, validar formularios, crear animaciones y comunicarse con servicios web.

Conceptos básicos

  • Variables: guardan datos que el programa puede utilizar.
  • Funciones: agrupan instrucciones para realizar una tarea.
  • Eventos: acciones como click, mouseover, change o submit que pueden activar código.
