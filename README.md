# Bella Flor — proyecto web mejorado

Proyecto académico de desarrollo web.

## Cambios realizados
- Interfaz visual mejorada conservando la identidad de Bella Flor.
- Bootstrap 5.3.3 incorporado.
- Carousel de Bootstrap con efecto `carousel-fade` (crossfade).
- JavaScript para:
  - modo claro/oscuro con localStorage;
  - entrada suave de páginas;
  - aparición de secciones al hacer scroll;
  - navegación interna suave;
  - interacción de productos;
  - buscador de las 15 herramientas.
- Nueva página `herramientas.html` con 15 herramientas de Google y una explicación general de su uso.
- Diseño responsive para computadora y celular.
- Menú actualizado en todas las páginas.

## Nota sobre las herramientas
La página presenta usos generales de herramientas de Google. La disponibilidad de funciones avanzadas puede variar según la cuenta, edición o plan de Google.
