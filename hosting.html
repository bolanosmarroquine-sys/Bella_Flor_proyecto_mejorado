Web Hosting y Dominios

Cómo pasar de archivos en una computadora a un sitio web disponible en internet.

¿Qué es Web Hosting?

El hosting es el servicio que proporciona espacio y recursos para almacenar los archivos de un sitio y hacerlos accesibles por internet.

Tipos de hosting

Compartido

Varios sitios utilizan recursos de un mismo servidor. Es una opción económica.

VPS

Un servidor físico se divide en entornos virtuales con recursos más controlados.

Nube

Utiliza infraestructura distribuida y puede escalar recursos según las necesidades.

¿Cómo funciona Vercel?

Vercel es una plataforma de despliegue que puede conectar un repositorio de GitHub con un proyecto web. Al realizar cambios y subirlos al repositorio, Vercel puede construir y publicar una nueva versión del sitio. Para este proyecto, una página estática de HTML, CSS y JavaScript puede desplegarse directamente.

💻 Código→🐙 GitHub→▲ Vercel→🌎 Sitio web

¿Qué es un dominio?

Un dominio es el nombre legible que las personas utilizan para llegar a un sitio web, por ejemplo bellaflor.com. El TLD es la terminación como .com, .net u .org. Un subdominio es una parte que aparece antes del dominio principal, como blog.ejemplo.com.

Propagación DNS

DNS relaciona un nombre de dominio con la ubicación del servicio que responde por él. Cuando se cambia un registro DNS, los servidores y dispositivos necesitan actualizar la información almacenada en caché; por eso la modificación puede tardar en verse en todas partes.

1. Registrar dominio→2. Configurar DNS→3. Actualización de servidores→4. Navegador encuentra el sitio
