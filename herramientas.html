15 herramientas de Google

Una selección de herramientas que pueden servir para estudiar, organizar información, trabajar en equipo y crear contenido.

HERRAMIENTA 01
✉️

Gmail

Correo electrónico.

Permite enviar, recibir y organizar correos. Se usa creando una cuenta, redactando mensajes y usando etiquetas o búsquedas para encontrar información.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 02
📁

Google Drive

Archivos en la nube.

Sirve para guardar archivos en internet y compartirlos. Se puede crear una carpeta, subir documentos y elegir quién puede verlos o editarlos.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 03
📝

Google Docs

Documentos.

Permite escribir y editar documentos desde el navegador. Varias personas pueden trabajar en el mismo archivo y los cambios se guardan automáticamente.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 04
📊

Google Sheets

Hojas de cálculo.

Se utiliza para organizar datos, hacer operaciones, tablas y gráficos. Los archivos pueden compartirse para trabajar en equipo.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 05
📽️

Google Slides

Presentaciones.

Sirve para crear presentaciones con texto, imágenes y otros elementos. Se pueden compartir y presentar directamente desde el navegador.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 06
📋

Google Forms

Formularios y encuestas.

Permite crear preguntas, encuestas y cuestionarios. Las respuestas pueden recopilarse y analizarse en una hoja de cálculo.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 07
🎥

Google Meet

Videollamadas.

Permite reunirse por video y audio. Se utiliza entrando a una reunión mediante un enlace o creando una nueva reunión.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 08
📅

Google Calendar

Calendario.

Ayuda a organizar actividades, fechas y reuniones. Se crean eventos indicando día y hora y, si se necesita, se invita a otras personas.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 09
💬

Google Chat

Mensajería.

Permite conversar mediante mensajes y espacios de trabajo. Es útil para comunicarse y coordinar actividades con otras personas.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 10
🗒️

Google Keep

Notas.

Sirve para guardar notas, listas y recordatorios. Se pueden organizar las notas con colores, etiquetas y fijación.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 11
🌐

Google Sites

Sitios web.

Permite crear sitios web sencillos sin tener que programar todo desde cero. Se agregan páginas, texto, imágenes y otros elementos.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 12
🤖

Google Gemini

Asistente de IA.

Es un asistente de inteligencia artificial que puede ayudar a generar ideas, explicar temas, resumir información y apoyar diferentes tareas. Algunas funciones dependen del plan.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 13
🎬

Google Vids

Creación de videos.

Ayuda a crear videos para explicar ideas, proyectos o información. Google lo incluye entre sus aplicaciones de Workspace; algunas funciones pueden depender del plan.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 14
⚙️

Google Apps Script

Automatización.

Es una plataforma basada en JavaScript para automatizar y ampliar Google Workspace. Puede crear acciones que conecten aplicaciones como Sheets, Docs o Gmail.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.
HERRAMIENTA 15
☑️

Google Tasks

Tareas.

Permite crear listas de tareas y organizar pendientes. Se pueden añadir fechas y consultar las tareas desde servicios de Google compatibles.

💡 Para un estudiante: puede ser útil para organizar trabajos, compartir información o colaborar con compañeros.

¿Por qué elegimos estas herramientas?

Se escogieron porque cubren actividades diferentes: comunicación, almacenamiento, documentos, datos, presentaciones, reuniones, organización, creación de sitios y automatización. Google presenta varias de estas aplicaciones dentro de su ecosistema de Workspace y su Learning Center las organiza según el tipo de trabajo que permiten realizar.

Nota: que una herramienta tenga una opción gratuita no significa que todas sus funciones avanzadas sean gratuitas. Google indica que algunas funciones de Gemini y otras capacidades dependen del plan o edición disponible.

Fuentes consultadas

  • Google Workspace Learning Center: información y guías de aplicaciones.
  • Google Workspace: listado de aplicaciones y sus funciones.
  • Google Docs Editors Help: funciones y disponibilidad de aplicaciones.
