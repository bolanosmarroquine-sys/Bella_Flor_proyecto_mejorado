jQuery

Una librería de JavaScript creada para simplificar tareas comunes del desarrollo web.

¿Qué es jQuery?

jQuery es una librería de JavaScript que nació para hacer más sencilla la manipulación del DOM, el manejo de eventos, las animaciones y otras tareas, especialmente cuando existían diferencias entre navegadores.

Sintaxis básica

$(selector).accion();

El símbolo $ es la función principal de jQuery. Por ejemplo:

$("#mensaje").text("Hola Bella Flor");

Ventajas y desventajas

VentajasDesventajas
Sintaxis corta y fácil para tareas comunes.JavaScript moderno ya incluye muchas funciones que antes requerían jQuery.
Facilita animaciones y eventos.Agregar una librería externa aumenta dependencias.
