JSON

Un formato ligero y muy utilizado para representar e intercambiar datos.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto fácil de leer y escribir que permite representar información estructurada y transmitirla entre aplicaciones.

Clave y valor

{
  "nombre": "Ramo Rosado",
  "tipo": "Ramo",
  "precio": 18.00,
  "disponible": true
}

Los objetos utilizan llaves { }, los datos se organizan mediante pares clave-valor y los arreglos utilizan corchetes [ ].

Objeto JavaScript vs. cadena JSON

Objeto JavaScriptJSON
{ nombre: "Ramo", precio: 18 }{ "nombre": "Ramo", "precio": 18 }
Es un objeto que el programa puede manipular.Es texto con formato definido para intercambio de datos.

¿Cómo se utiliza?

Una aplicación puede solicitar datos a un servidor o API. El servidor responde con JSON y JavaScript puede convertir esa información en objetos para mostrar productos, precios, usuarios u otros datos en la interfaz.
